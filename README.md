# Paper Translation

将各学科学术论文完整翻译为中文，提炼关键内容，并使用用户模板或内置默认模板生成 Word。

## 安装

将仓库中的 `paper-translation` 目录复制到 `~/.codex/skills/`。重新加载技能后，可使用 `$paper-translation` 调用。

## 使用

提供论文文件并说明翻译范围。默认每篇交付一份中文 Word，包含关键内容提炼、全文译文、公式、原图及参考文献。优先遵循当次用户要求和模板。

## 验证与能力边界

Skill 已通过结构校验，内置模板已完成 DOCX 结构检查；模板视觉复核尚未完成。每次生成最终 Word 时仍需逐页渲染检查。AxMath / MathType 参考文件描述接入流程，尚未附带已验证的自动调用脚本，不包含商业插件安装包或许可证。

默认模板公开发布前已清除作者、最后修改者、WPS 用户标识和历史自定义检查记录；正文及样式保留。
